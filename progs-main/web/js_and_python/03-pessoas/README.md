# Instruções

## Pasta backend

- Instalar as bibliotecas flask e flask_cors

```pip3 install flask```

```pip3 install flask_cors```

- Executar o backend

```python3 app.py```

## Pasta frontend

- Executar um servidor web:

```python3 -m http.server```

- Acessar a página no navegador:

localhost:8000
